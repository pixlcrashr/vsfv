AuditLogEntry

AuditLogEntry is an immutable record of a single change to a resource.

One entry is created per mutating API call: an update that changes multiple

fields at once results in a single entry containing the per-field diff.

Entries are append-only and can never be modified or deleted.

FieldTypeLabelDescription
name string

The resource name of the audit log entry. Format: auditLogEntries/{audit_log_entry}

uid string

The UUID of the audit log entry.

resource string

The full resource name of the object this entry refers to. Format: e.g. organizations/{organization}/accounts/{account} or users/{user}

organization string

The resource name of the organization the audited resource belongs to. Empty for resources that are not subordinated under an organization (e.g. users, groups, organizations themselves). Format: organizations/{organization}

action AuditLogEntry.Action

The kind of change that was recorded.

actor string

The resource name of the user who performed the change. Empty if the change was performed by the system. Format: users/{user}

changes AuditLogEntry.Change repeated

The per-field changes recorded by this entry.

timestamp google.protobuf.Timestamp

The time at which the change was recorded.

AuditLogEntry.Change

Change describes a single field-level modification within an audit log

entry. Values are rendered as strings; an empty value means the field was

absent (or null) in that state. For creations, old_value is empty for all

changes; for deletions, new_value is empty for all changes.

FieldTypeLabelDescription
field string

The name of the changed field (snake_case, as in the API resource).

old_value string

The field value before the change (empty for creations).

new_value string

The field value after the change (empty for deletions).

AuditLogService

AuditLogService provides read-only access to the global, append-only audit

log. Entries can be retrieved individually by resource name or listed with

filters. The audit log itself is not bound to any organization: entries for

resources below an organization carry that organization's resource name and

can be filtered by it.
